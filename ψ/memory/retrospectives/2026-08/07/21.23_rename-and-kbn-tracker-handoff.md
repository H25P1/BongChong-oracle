## Lessons Learned

- When recommending an approach to fetch/locate external content, do a cheap existence check (or ask a direct factual question) before presenting it as "(Recommended)" in an AskUserQuestion — a confident-sounding option with no supporting evidence wastes more of the human's time than an honest "I don't know yet, let me check."
- For claude.ai browser automation: the header search icon needs `cmd+f` (or click-then-verify-a-real-input-appeared) — a plain click alone renders only a keyboard-shortcut tooltip, not an active search field. Verify a search box is actually focused before typing into it.
- When advisor flags that a rename/edit touches both tracked and untracked files, back up untracked files before editing (they have no git undo) — cheap insurance, should be a reflex on any identity-wide sweep, not something that needs advisor to point out every time.
- When a project-identity rename touches infrastructure outside the immediate task (local folder names, remote repo names, symlinks pointing at either), treat those as a separate decision to defer to the human rather than something to resolve unilaterally just because it's mechanically possible — even if "the user already said rename everything."
